# Деньги: курс, резервы, долг

Следующий шаг после торговли. Формулы модели — в
[`08-economic-model.md`](./08-economic-model.md), замеры — в
[`09-reality-check.md`](./09-reality-check.md).

## Зачем

Измерено, а не предположено. Тот же мир с бездонной казной у всех:

| | Как есть | Деньги без предела |
|---|---|---|
| Реальный ВВП | 16.04 трлн | 18.02 трлн |
| Цен на границе коридора | 18.5% | 6.1% |
| Стран без денег к третьему году | 60 | 0 |

Два триллиона ВВП и двенадцать процентов цен стоят ровно здесь.

## Что не так сейчас

Деньги приходят только за экспорт и уходят только за импорт. Это храповик в одну
сторону: у кого сальдо минусовое, тот доезжает до нуля и перестаёт ввозить.

В жизни между странами два потока, а у нас один.

**Текущий счёт** — деньги за товары. Он есть.

**Капитальный счёт** — кредиты, покупка чужих облигаций и акций, вложения в чужие
заводы, переводы работников, движение резервов. Его нет.

В сумме эти два потока всегда ноль. США покупают на 982 млрд больше, чем продают, и не
остаются без долларов потому, что те же доллары возвращаются к ним покупкой облигаций и
активов. Дефицит не проедается, а **финансируется**.

## Три части

### 1. Курс

`Country.ExchangeRate` — сколько местных денег за мировую единицу. Двигается от сальдо
тем же правилом, что уже работает у цен:

```
перекос = (импорт − экспорт) / (импорт + экспорт)
курс    = курс × (1 + шаг × перекос)
```

Это буквально `Prices.MoveFromBalance`, только товар — деньги страны. Курс и есть цена
валюты, отдельный механизм ему не нужен.

Что он делает: у страны с дефицитом валюта дешевеет, импортное дорожает в местных
деньгах, свой экспорт дешевеет для чужих. Дефицит закрывается сам.

Мировая единица — условная, ничья: тысяча долларов 2020 года как мера, а не как чья-то
валюта. Какую валюту на самом деле держат в резервах — отдельный вопрос, и пусть он
решается сам собой. Так резервная валюта станет тем, чем и является в жизни: результатом
доверия, а не назначением.

### 2. Резервы

`Treasury.Balance` сейчас означает сразу и внутренние деньги, и валюту. Это разные вещи:
свою валюту государство может напечатать, чужую — только заработать или занять.

- `Treasury.Balance` — местные деньги, внутренние расчёты
- `Treasury.Reserves` — то, чем платят за импорт

**Резервы — не одно число, а набор вложений.** `Economy/Reserves.cs`, внутри записи
`Reserve(ReserveKind Kind, byte Issuer, Money Amount)`.

| Вид | Ликвидность | Доход | Цена зависит от | Можно заморозить |
|---|---|---|---|---|
| `ForeignCurrency` | сразу | нет | курса эмитента | да |
| `Bond` | сразу, с потерей | купон | ставки эмитента | да |
| `Equity` | сразу, с потерей | дивиденд | рынка акций | да |
| `Metal` | сразу | нет | мировой цены товара | нет, если хранится дома |
| `Crypto` | сразу | нет | своего рынка | нет |

`Issuer` хранится ради последней колонки. Заморозка чужих резервов — настоящий рычаг
(2022 год), и без эмитента его не сделать. Заодно отсюда сама собой выходит причина
держать золото и криптовалюту: их отобрать нельзя.

Методы: `Money Liquid` — чем можно заплатить прямо сейчас; `Money Value` — сколько стоит
всё; `bool TrySpend(Money)` — тратит с самого ликвидного; `void Freeze(byte issuer)`.

**В первой версии только `ForeignCurrency`.** Остальные виды требуют того, чего ещё нет:
рынка облигаций, рынка акций, золота в `GoodType`. Но форма закладывается сразу, чтобы
потом не переписывать всё, что резервов касается.

### 3. Долг

`Treasury.Debt` — не одно число, а список займов. `Economy/Loan.cs`:

```csharp
public sealed class Loan
{
    public int Id { get; }
    public LoanSource Source { get; }   // Domestic | Foreign | Multilateral
    public byte? Lender { get; }        // кто дал; пусто у внутреннего рынка
    public Money Principal { get; }
    public RateKind RateKind { get; }   // Fixed | Floating
    public int FixedRate { get; }       // сотые доли процента годовых
    public int Spread { get; }          // надбавка к ключевой ставке у флоатера
    public int MaturityDay { get; }     // 0 — бессрочный
}
```

**Почему список, а не сумма.** Три вещи иначе не сделать:

- **Перезанять дорогое.** Игрок должен видеть, что у него висит заём под 14%, и гасить
  сначала его. По одному числу этого не видно.
- **Флоатеры.** У займа с плавающей ставкой расход меняется вслед за `Country.KeyRate`.
  Поднял ставку против инфляции — вырос свой же процентный расход. Это настоящая
  развилка, и она требует знать, какая часть долга плавающая.
- **Дефолт по частям.** Отказаться можно по внешнему долгу, а по внутреннему — это уже
  не дефолт, а инфляция или заморозка вкладов, с другими последствиями. Разделение по
  `LoanSource` даёт обе дороги.

Ставка займа: `Fixed` → `FixedRate`; `Floating` → `Country.KeyRate` эмитента плюс
`Spread`. Проценты за тик — `долг × ставка / 365`.

`Country.KeyRate` в сотых долях процента: у США в 2020-м 25, у зоны евро 0, у России 425,
у Турции 1700. Это же и рычаг игрока.

**Откуда деньги на заём.** Даёт не воздух, а другая страна из своих лишних резервов —
это и есть капитальный счёт. Деньги в мире остаются в сохранности, а «сумма резервов по
всем странам не меняется» остаётся инвариантом в тестах. Заодно механика получается
настоящая: Китай кредитует США, а не абстрактный банк.

**Внутренний заём в первой версии не делаем.** Деньги на него должны прийти от своих
граждан и компаний, а внутреннего денежного оборота ещё нет — зарплаты и налоги идут в
шаге «Труд». `LoanSource.Domestic` пока просто существует в перечислении.

**Дефолт.** Когда резервы в нуле, а проценты платить нечем. Кредиторы теряют тело,
должника не пускают на кредитный рынок несколько лет, курс валится. Это не изъян, а
хороший игровой узел: долговой кризис, МВФ, реструктуризация.

### 4. Дать в долг могут и не дать

Выше молча предполагалось, что заёмщику всегда найдётся кредитор. Это неправда, и
неправда как раз в самых интересных случаях.

Живой пример. Государство выходит занимать на своём рынке под ставку, которую считает
приемлемой, — банки не берут, дорого им не дают, дёшево не хотят. Снаружи не занять
вовсе: санкции. Тогда центробанк печатает деньги и раздаёт банкам через репо, банки на
них покупают гособлигации, и формально заём рыночный, а по сути это эмиссия. Дальше
инфляция.

Здесь три отдельные вещи, и каждую надо сделать отдельно.

#### Заём — это торг, а не выдача

`Economy/CreditMarket.cs`. У каждого возможного кредитора своя **требуемая ставка** к
этому заёмщику:

```
требуемая = безрисковая + премия за риск + политическая надбавка
```

Заёмщик объявляет, сколько хочет и до какой ставки готов дойти — `Country.MaxBorrowRate`.
Кредиторы выстраиваются от самого дешёвого, заявка набирается сверху вниз, и ставку
задаёт последний, кто вошёл. Кончились согласные раньше, чем набралась сумма, — **аукцион
не состоялся**, целиком или частично.

Это не выдумка: так и работают аукционы гособлигаций, и их регулярно объявляют
несостоявшимися, когда заявки идут по неприемлемой цене.

Премия за риск считается из состояния игры:

| Из чего | Как считается |
|---|---|
| Способность вернуть | `Debt.BurdenToExports` — внешний долг к годовому экспорту. За 200% начинается зона риска |
| Прошлые отказы | `Country.DefaultedOnDay` — после дефолта на рынок не пускают годами |
| Уже занятое | чем больше должен, тем дороже следующий рубль |
| Политика | санкции, союзники, война — через `Politics` |

Для сверки есть настоящие числа: доходность десятилетних бумаг в 2020-м — США 0.9%,
Германия −0.5%, Россия 6%, Турция 12%, а страна после дефолта на рынок просто не выходит.

#### Кредиторы бывают разные, и хотят они разного

| Кто | Откуда деньги | Чем руководствуется |
|---|---|---|
| Другая страна | свободные резервы | доход, союзничество, рычаг влияния |
| Свои банки | внутренние деньги | ставка против ключевой, требования регулятора |
| Своё население | сбережения | ставка против инфляции, доверие |
| МВФ и подобные | вне модели | даёт под условия, а не под ставку |

Внутренние кредиторы появятся вместе с зарплатами и налогами. Но `LoanSource` уже
разделяет их с самого начала — именно потому, что отказать могут по-разному и дефолт по
ним разный.

#### Печатный станок как последний выход

`Economy/CentralBank.cs` с методом `Emit(Money amount, EmissionKind kind)`.

Когда занять не вышло, а платить надо, остаётся создать деньги. Это работает — и это
имеет цену:

```
рост денежной массы = эмиссия / Country.MoneySupply
местные цены   × (1 + рост)
Country.ExchangeRate ÷ (1 + рост)
```

Грубая количественная теория, и для крупной эмиссии она как раз верна. Стартовая
`MoneySupply` — из нового `data/economy/money-supply.json`, денежный агрегат M2 за 2020
год: США 19.1 трлн $, Китай 218 трлн ¥, Россия 58 трлн ₽.

`EmissionKind` — `Open` или `ThroughBanks`. Экономически это одно и то же: деньги
созданы, инфляция будет. Разница политическая. «Центробанк напечатал» и «банки купили
гособлигации» — разные заголовки, и стоить в доверии они должны по-разному. Поэтому вид
эмиссии хранится, хотя на цены влияет одинаково.

Проверять это есть на чём: настоящие случаи большой эмиссии — Венесуэла, Зимбабве,
Турция — дают связку между ростом денежной массы, ценами и курсом.

## Оговорка: курс работает только при чувствительном спросе

Сейчас завод заказывает своё сырьё по рецепту независимо от цены, а заявка на рынок
считается в штуках от нормы запаса. Подешевевший экспорт никто не станет покупать больше,
потому что покупают не по цене.

Значит, до курса или вместе с ним нужен четвёртый кусок: **заявка, зависящая от цены**.
Вроде «цена вдвое выше обычной — беру вдвое меньше». Без него курс будет двигаться и ни
на что не влиять.

Частично это пересекается с шагом «Труд»: там появляется зарплата, а с ней и то, сколько
население может себе позволить.

## Порядок работ

Шаги 1–5, 7 и 8 сделаны, замеры — в [`09-reality-check.md`](./09-reality-check.md).
Шаг 6, печатный станок, отложен: местными деньгами пока нечего оплачивать, внутренних
расходов у государства нет. Он вернётся вместе с зарплатами и налогами.

Восемь шагов. Первые три закрывают измеренный разрыв, остальные добавляют глубину и
игровые узлы. Каждый шаг — отдельный коммит, тесты зелёные до и после, строки в
[`09-reality-check.md`](./09-reality-check.md) обновляются в том же коммите.

### 1. Эластичность спроса

Без этого весь остальной этап бессмысленен: подешевевший экспорт никто не купит больше,
потому что сейчас покупают не по цене.

| | |
|---|---|
| Файлы | `Economy/Elasticity.cs`, поле `elasticity` в `data/economy/goods.json` |
| Правит | `Simulation.Trade()` — заявка, `Simulation.CollectInputs()` — заказ завода |
| Формула | `множитель = 1 − эластичность × (цена / обычная − 1)`, зажат в 0.1…2 |
| Данные | еда −0.4, топливо −0.25, сырьё для заводов −0.5, потребтовары −1.2 |
| Тесты | `ExpensiveGoodIsOrderedLess`, `CheapGoodIsOrderedMore`, `InelasticGoodBarelyMoves` |
| Сдвинет | экспорт слегка вниз, зато цена начинает на что-то влиять |

Обычная цена — `Prices.StartOf(good)`: она уже хранится ради коридора.

### 3. Курс

| | |
|---|---|
| Файлы | `Country.ExchangeRate`, `Country.KeyRate` |
| Правит | `Simulation` — движение курса от сальдо после `Trade()` |
| Формула | `Prices.MoveFromBalance` от `(импорт − экспорт)` |
| Тесты | `DeficitWeakensTheCurrency`, `SurplusStrengthensIt`, `WeakCurrencyCutsImports` |
| Сдвинет | стран без денег с 60 вниз, цен на рельсах с 18.5% вниз |

Курс стартует у всех с единицы. Настоящие курсы (RUB 72, JPY 107, EUR 0.88 за доллар)
понадобятся, когда цены начнут показывать игроку в местных деньгах, — не раньше.

Петля замыкается только вместе с шагом 1: курс упал → местная цена импортного выросла →
эластичность срезала заявку → дефицит закрылся.

### 6. Печатный станок

Идёт вместе с пятым: отказ в кредите без станка — тупик, станок без отказа — рычаг,
которым незачем пользоваться.

| | |
|---|---|
| Файлы | `Economy/CentralBank.cs`, `Economy/EmissionKind.cs`, `Country.MoneySupply` |
| Данные | `data/economy/money-supply.json` — M2 за 2020: США 19.1 трлн $, Китай 218 трлн ¥, Россия 58 трлн ₽ |
| Формула | `рост = эмиссия / MoneySupply`; местные цены × (1 + рост), курс ÷ (1 + рост) |
| Тесты | `EmissionRaisesLocalPrices`, `EmissionWeakensTheCurrency`, `EmissionKindChangesNothingInTheNumbers` |
| Сверка | связка эмиссии с ценами и курсом по Венесуэле, Зимбабве, Турции |

`EmissionKind.Open` и `ThroughBanks` считаются одинаково. Разница политическая и вылезет

## Чего в этом этапе всё же не будет

Отдельными шагами позже, каждый требует того, чего ещё нет:

| Что | Чего ждёт |
|---|---|
| Внутренний заём у банков и населения | зарплат и налогов, шаг «Труд» |
| Резервы в облигациях, акциях, металлах, крипте | рынков под них; форма уже заложена |
| Прямые вложения в чужие заводы | компаний |
| Переводы работников домой | миграции |
| МВФ и подобные | они дают под условия, а не под ставку |
| Инфляция от дефицита товаров и роста зарплат | шага «Труд»; сейчас инфляция только от эмиссии |
