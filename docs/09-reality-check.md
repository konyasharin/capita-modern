# Сверка с реальностью

С переходом на простую модель (`03-model.md`) экономика больше не калибруется по
реальным числам. Реальный мир задаёт только старт, поэтому сверяется именно он; дальше
проверяется не точность, а ровный ход. Замеры прежней реалистичной модели — в истории
git (до коммита `5c3f614`).

## Как получить числа

```bash
dotnet run --project src/CapitaModern.Headless -c Release -- 40
```

- Рост 1.6–1.8% в год: 1.5% техпрогресса плюс прирост населения. В жизни мир рос на 2.5–3.5%.
- Первый год — посадка на склады: недельный ВВП мира меняется до 9.75%. Дальше — 0.2%.
- Сильнее всех дрожат Китай, Индия, Мексика, Индонезия, Турция: до 1–1.4% за неделю.
- Северная Корея закрывает нужды на 65% — план без компаний строит мало.

## Чего ещё нет

- Лесозаготовка в России работает на 1% мощности: стартовая расстановка даёт ей тысячи
  лесопилок, а спроса на лес нет. Нужна расстановка добычи по мировому спросу, а не по
  месторождениям.
- Компаний меньше, чем отраслей в стране: где именной компании нет, строит одна сборная
  «<ISO> <отрасль>».
