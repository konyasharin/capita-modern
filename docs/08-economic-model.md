# Экономическая модель

Полный расчёт экономики: что из чего считается, откуда берутся числа и какой
погрешности ждать. Документ-справочник, чтобы не переизобретать одно и то же.

Правило, которому подчинено всё остальное: **показатель выводится из состояния игры,
а реальные данные годятся для стартового состояния и для проверки, но не как
постоянная внутри формулы.**

## 1. Что модель обязана посчитать

| Показатель | Кому нужен |
|---|---|
| Цена каждого товара в каждой стране | торговля, решения о стройке, ВВП |
| Зарплата | уровень жизни, себестоимость, недовольство |
| Занятость и безработица | политика, настроения |
| Прибыль предприятия | кто и что строит |
| ВВП и ВВП на душу | главное число для игрока |
| Инфляция | обратная связь на печать денег и дефицит |
| Торговый баланс и курс валюты | внешняя торговля |
| Уровень жизни, голод, смертность | последствия решений |

## 2. Величины

Все количества целочисленные, дробность через масштаб: плавающая точка копит ошибку
за тысячи тиков и ломает воспроизводимость.

| Величина | Тип | Масштаб | Смысл |
|---|---|---|---|
| Количество товара | `GoodAmount` | 10 000 | единицы товара |
| Население | `Population` | 1 000 | человек |
| Деньги, цена | `Price` | 10 000 | местная валюта |
| Загрузка | `long` | `Load.Full` | доля мощности |
| Доли и ставки | `int` | 100 | проценты |

Тик — сутки. Год — 365 тиков.

## 3. Кто действует

**Продавец** (`Producer`) — у кого склад, деньги, цены и заводы. Сегодня один на
страну, государство. Дальше рядом появятся компании, а поле `RegionId` даст им место.

**Население** области — потребитель и источник рабочих рук одновременно.

**Правительство** — законы, налоги, бюджет. Меняет правила, а не производит.

## 4. Производство

```
доля входа   = склад[товар] / заказано[товар]                    0..1
доля рабочих = свободные рабочие / нужно рабочих                 0..1
загрузка     = min(все доли входов, доля рабочих)
выпуск       = базовый × количество × загрузка × эффективность
расход       = вход  × количество × загрузка
```

Эффективность множит **выпуск, а не расход**: изношенный завод с той же рудой даёт
меньше стали, а не ест больше руды.

```
эффективность = состояние × технология × квалификация
```

| Множитель | Откуда | Диапазон |
|---|---|---|
| Состояние | 1 − износ, восстанавливается ремонтом | 0 … 1 |
| Технология | уровень страны к мировому переднему краю | 0.3 … 1.2 |
| Квалификация | доля обученных среди работающих | 0.4 … 1.1 |

Стартовые значения — из обратной задачи: подобрать так, чтобы производительность
сошлась с реальной. Дальше они живут своей жизнью.

**Добыча ограничена месторождением.** Не только «есть или нет», а потолок:

```
выпуск добычи ≤ мощность месторождения
```

Отсюда сама собой берётся рента: спрос упирается в потолок, цена растёт выше
себестоимости, и владелец редкого ресурса получает сверхприбыль. Отдельного слагаемого
для ренты не нужно, она следствие.

Запас месторождения истощается: выработал — мощность падает.

## 5. Труд и зарплата

```
предложение труда = население × доля работающих     (около 45%)
спрос на труд     = Σ (рабочие × количество × загрузка)
напряжённость     = спрос / предложение
```

Если спроса больше предложения, заводы не укомплектованы и загрузка падает — это и
есть нехватка рук. Безработица — обратный случай.

Зарплата тянется к тому, что работник производит, и подталкивается рынком труда:

```
целевая  = доля труда × (выпуск×цена − входы×цена) / рабочие
зарплата = зарплата + скорость × (целевая × напряжённость − зарплата)
```

Доля труда около половины добавленной стоимости, остальное капиталу. Скорость малая:
зарплаты меняются месяцами, а не за сутки.

**Нижней границы нет намеренно.** Люди живут и на зарплату, которой не хватает на еду,
— просто хуже. Роль «пола» играют последствия: недоедание, смертность, недовольство.
Запрет в формуле их бы отменил.

## 6. Капитал

Завод — это капитал, и он изнашивается.

```
износ за тик = 1 / срок службы            (порядка 20 лет = 7300 тиков)
состояние    = состояние − износ + ремонт
ремонт стоит = buildCost × восстановленная доля
```

Стройка тратит `buildCost` — стройматериалы, металлы, электронику. Отсюда экономика
замыкается сама на себя и рост становится капиталоёмким.

**Электроника нужна на стройку и ремонт, а не на работу.** НПЗ с уже установленной
системой управления гонит бензин без единого нового чипа; новый НПЗ без электроники не
построить. Поэтому она вход только там, где физически уходит в изделие.

```
прибыль = выручка − сырьё − зарплаты − ремонт − налоги
доходность = прибыль за год / buildCost
```

Строят, пока доходность выше порога. Это и есть решение частного капитала.

## 7. Цены

Цена — свойство положения дел, а не вещи. Считается она от того, **на сколько суток
хватит запаса**:

```
покрытие = наличие / спрос за сутки
перекос  = (норма − покрытие) / (норма + покрытие)        −1 … 1
цена     = цена × (1 + шаг × перекос)
```

`Prices.TargetCoverDays = 40` — норма запаса. В жизни отношение запасов к продажам в
обрабатывающей промышленности США держится около полутора месяцев, отсюда и число.

Сравнивается именно покрытие, а не склад со спросом напрямую: склад — это запас, спрос —
расход за сутки, величины разной размерности. Иначе цену задавал бы размер складов, а не
нехватка: страна с месячным запасом вечно роняла бы цену, даже если сырья ей впритык.

**Шаг ограничен.** `Prices.StepPercent = 2` за тик, тик — сутки. Это не «в жизни так
медленно»: газовый кризис 2021 года (×11 за год) — это 0.63% в сутки, втрое меньше
нашего потолка. Сам потолок при полном перекосе дал бы ×1380 за год.
Ограничение нужно по трём причинам:

- Прыгает **спотовая котировка**, а мы считаем среднюю цену, по которой платит вся
  промышленность страны. Она и в жизни ползёт: долгосрочные контракты, тарифы, склады.
- Формула — контур обратной связи с задержкой в тик. Без демпфера паутина расходится в
  колебания.
- Ноль — состояние без выхода: товар, цена которого туда упала, уже никогда не
  подорожает настолько, чтобы его стали делать.

Резкое приходит событием — `Prices.Shock(good, percent)`: эмбарго, удар по заводу,
паника. В жизни цена улетает от новости, а не оттого, что склад просел на процент.

**Коридор.** `Prices.MaxSwingTimes = 100` — во сколько раз цена может уйти от стартовой
в любую сторону. Это подпорка, а не экономика: товар, которого в стране нет совсем,
сейчас дорожает полным шагом вечно — купить его негде, торговли нет, а отказаться от
него заводы не умеют, цену они не видят. Уйдёт вместе с торговлей и спросом, который
смотрит на цену.

**Себестоимость — нижняя граница, а не источник цены.**

```
себестоимость = (сырьё + зарплаты + амортизация) / выпуск
```

Если рыночная цена ниже себестоимости, производство убыточно: сначала останавливается,
потом закрывается. Как источник цены себестоимость не годится — проверено расчётом,
половина цен уезжает в разы, потому что она не знает ни про ренту, ни про разработку,
ни про масштаб серии.

Стартовые цены: биржевым товарам — реальные 2020 года, условным (электроника,
потребтовары, медикаменты, военное) — из себестоимости, потому что настоящей цены за
нашу выдуманную единицу не существует.

### Сверка скорости с жизнью

Пять независимых эпизодов — газ, литий, нефть, уголь, удобрения — формула проходит за их
настоящий срок при запасе в 20–30 суток, то есть при половине нормы. Таблица и остальные
замеры — в [`09-reality-check.md`](./09-reality-check.md).

## 8. Дележ дефицита

Пока рынка нет, дефицит делится по весам отраслей:

```
доля = вес × заказ / Σ(вес × заказ)
```

Вес ставится законом и чего-то стоит: денег, поддержки бизнеса или политического
кризиса. Полная таблица законов — в `07-economy.md`.

Когда появятся компании и цены, дележ станет рыночным: получает тот, кто платит. Веса
останутся как рука государства поверх рынка — приоритетное право, разнарядка, реквизиция.

## 9. Потребление и уровень жизни

Ставки на миллион человек в сутки лежат в `consumption.json`. Но потребление зависит
от дохода, и это надо учитывать — закон Энгеля:

```
ставка = базовая × (доход / опорный доход) ^ эластичность
```

| Товар | Эластичность | Поведение |
|---|---|---|
| Еда | 0.1 … 0.3 | почти не растёт с доходом, есть насыщение |
| Потребтовары | 1.0 … 1.3 | растут вместе с доходом |
| Медикаменты | 0.8 … 1.0 | растут почти пропорционально |
| Услуги | 1.3 … 1.6 | растут быстрее дохода |

Без этого бедная страна будет «хотеть» столько же телевизоров, сколько богатая, и
дефицит окажется бессмысленным.

**Недостача имеет последствия:**

```
голод         → рост смертности с задержкой в месяцы
нет лекарств  → рост смертности, слабее
нет товаров   → падение настроений, не смертности
```

## 10. Деньги, налоги, инфляция

**Налоги** — единственный источник казны:

```
налог = ставка × база
```

базой может быть добавленная стоимость, прибыль, продажи или зарплата — это разные
налоги с разными последствиями, ставки задаются законами.

**Инфляция** возникает сама из связки зарплат и цен: подорожала еда — выросли
зарплаты — подорожало всё. Отдельной механики не нужно.

```
инфляция = рост среднего уровня цен за год
```

Печать денег добавляется как прямое увеличение казны без налога — и через спрос
разгоняет цены.

## 11. Внешняя торговля и курс

Логистика внутри страны и внешняя торговля — **одна механика**: обмен между двумя
продавцами.

```
выгодно, если цена у покупателя > цена у продавца + доставка + пошлина
доставка = расстояние × тариф × объём
```

Санкции и эмбарго — запрет на конкретную пару продавцов или товар.

**Курс валюты** выводится из торгового баланса:

```
профицит → спрос на валюту → курс растёт
дефицит  → курс падает
```

Начальное значение — из соотношения уровней цен. Показ в долларах — пересчёт по курсу,
только для интерфейса.

## 12. Чего в модели пока нет, а надо

**Услуги.** В реальности это около двух третей ВВП, а у нас их нет вовсе. Из-за этого
ВВП занижен втрое и сравнения с реальностью хромают. Устроены просто: производство
почти без сырья, только труд, потребляются на месте, через границу не возятся. Добавить
стоит рано — они чинят сразу и ВВП, и структуру занятости, и эффект Балассы-Самуэльсона
(в бедной стране услуги дёшевы, поэтому на ту же зарплату там можно купить больше).

**Натуральное хозяйство.** Часть бедного населения кормит себя сама, минуя рынок. Без
этого африканские страны в модели будут вымирать быстрее, чем следует.

**Переоборудование заводов.** Приоритет умеет только перераспределять сырьё; военный
рост в разы даёт перевод гражданских мощностей на военный выпуск. Ориентиры — в
`07-economy.md`.

## 13. Показатели

```
добавленная стоимость = выпуск×цена − сырьё×цена
ВВП страны            = Σ добавленная стоимость всех её продавцов
ВВП на душу           = ВВП / население
производительность    = добавленная стоимость / работник
уровень жизни         = потреблено на человека, а не доход
```

ВВП считается **по добавленной стоимости**, а не по выручке — иначе сырьё посчитается
столько раз, сколько раз перепродано.

## 14. Калибровка и погрешность

Измеренные значения — в [`09-reality-check.md`](./09-reality-check.md).

Реальные данные 2020 года — якорь для стартового состояния и мера проверки, не более.

| Что сверяем | С чем | Допустимо |
|---|---|---|
| Цены биржевых товаров | реальные 2020 | ±30% |
| Цены условных товаров | мировая ВДС отрасли | ±2 раза |
| Производительность по странам | ВДС обрабатывающей промышленности на занятого | ±2 раза |
| Мировая занятость | ~500 млн в промышленности | ±30% |
| Средняя зарплата | ~17 тыс. $ в год по миру | ±30% |
| Годовой выпуск товара | мировой выпуск 2019 | ±20% |

Известные источники погрешности, которые не убрать без новых механик:

- нет услуг — ВВП занижен примерно втрое;
- нет натурального хозяйства — бедные страны беднее реальных;
- завод везде одинаков, кроме множителя эффективности — тонкие различия между странами
  не воспроизводятся;
- нет рынков по местам — цена одна на страну, логистика внутри страны не считается.

## 15. Данные и инструменты

| Файл | Что в нём | Чем создаётся |
|---|---|---|
| `data/economy/prices.json` | стартовые цены, тыс. $ 2020 за единицу | руками, биржевые котировки |
| `data/economy/employment.json` | мировая занятость по отраслям | руками, МОТ и обзоры |
| `optimalWorkers` в `buildings.json` | рабочих на предприятие | `tools/gen-workers.mjs` |
| расход в рецептах | сколько сырья на выпуск | `tools/gen-recipes.mjs` |

`tools/check-economy.mjs` сверяет всё разом: убыточные рецепты, уровень зарплаты,
производительность по странам.

Состояние на сегодня: убыточных рецептов нет, мировая добавленная стоимость 15.7 трлн $
в год при реальных примерно двадцати, средняя зарплата 7100 $ в год на 1.1 млрд занятых.
Низкая зарплата ожидаема: восемь из десяти работников у нас — крестьяне.

## 16. Порядок построения

Сделано: производство, дележ по весам, потребление, население в областях, калибровка
рабочих и цен по реальным данным, цены от покрытия запаса.

1. **Торговля** — она же логистика, снимает главное искажение: сейчас мир работает на
   четверть мощности, а без неё половина цен за год упирается в коридор.
2. **Труд** — предложение, спрос, зарплата, безработица.
3. **Капитал** — износ, ремонт, стройка, прибыль.
4. **Услуги** — большой кусок ВВП и занятости.
5. **Последствия** — смертность от голода, настроения.
6. **Налоги, бюджет, инфляция.**
7. **Курс валют.**

Каждый шаг проверяется таблицей из раздела 14. Если после шага сверка ухудшилась,
причина в этом шаге, а не «где-то накопилось».
