# Война: фронт как процесс

Война не захватывает области. Война меняет поле владения ([`01-map.md`](./01-map.md)),
а граница едет следом.

## Тик фронта

Фронтовая ячейка — та, у которой есть сосед с другим владельцем, и владельцы в
состоянии войны. Их немного (тысячи из полумиллиона), поэтому они держатся отдельным
списком и только они пересчитываются.

Для каждой фронтовой ячейки:

```
push = attack(A, cell) - defense(D, cell)
t_D -= k * push * dt
```

Когда `t` защитника проваливается ниже 0.5 — ячейка меняет владельца, и `t` начинает
расти уже за атакующего. Переход непрерывный: скачка нет ни в данных, ни на экране.

После применения давления поле **размывается** (одна итерация лёгкого сглаживания по
фронтовой полосе). Это не косметика, а механика: размытие срезает иглы, не даёт
прорыву выродиться в нить шириной в ячейку и удерживает фронт гладким сам по себе.

## Направления атаки

Игрок не отдаёт приказ «взять регион». Он распределяет усилие по фронту:

- рисует стрелку или выделяет сектор фронта;
- туда уходит доля общего наступательного потенциала;
- в этом секторе `attack` выше, `t` защитника падает быстрее, фронт прогибается.

Сумма усилий ограничена, поэтому концентрация на одном направлении автоматически
ослабляет остальные — и там фронт может поехать в обратную сторону. Это и есть
основное тактическое решение игрока.

Выступ («клин») ограничен размытием и снабжением, поэтому он не превращается в
бесконечную иглу: чем глубже клин, тем длиннее его фланги и тем сильнее его срезает.

## Что входит в attack / defense

Стартовый набор, намеренно короткий:

| Множитель | Влияет на | Комментарий |
|---|---|---|
| Военный потенциал страны | attack, defense | из экономики: техника, боеприпасы |
| Доля усилия на направлении | attack | распределяется игроком |
| Снабжение | оба | падает с расстоянием до своей территории/центра |
| Рельеф ячейки | defense | горы/река дороже, равнина дешевле |
| Укрепления | defense | строятся, повышают `t` в полосе |

Расширять этот список нужно осторожно: каждый множитель делает поведение фронта менее
предсказуемым для игрока.

## Захват экономики

Отдельной механики захвата нет. Предприятие принадлежит тому, чей `owner` в ячейке
под его координатой. Промзона, разрезанная фронтом пополам, автоматически даёт двум
странам по половине предприятий — см. [`03-industry.md`](./03-industry.md).

## Открытые вопросы

- Нужны ли армии как объекты на карте, или только «потенциал + распределение»?
  По духу проекта — второе, но тогда неясно, как показывать перемещение сил.
- Мир/капитуляция: по потере доли территории, по экономике, вручную?
- Может ли фронт существовать без войны (напряжённость, спорные территории)?
