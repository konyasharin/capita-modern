# Интерфейс

## Верхняя панель

Занимает всю ширину, высотой 34 пикселя. Слева пока пусто — там будут кнопки разделов.
Посередине показатели страны игрока, справа дата.

| Показатель | Откуда берётся |
|---|---|
| Население | `GameWorld.PopulationOf` |
| Валовой продукт | `Simulation.ValueAddedOf` в постоянных ценах, на год |
| Мощности | сумма `Region.BuildingsCount` по стране |
| Инфляция | `Simulation.PriceLevelOf` против начала партии |
| Казна | `Treasury.Balance` |

Собирается кодом в `scripts/Ui/TopBar.cs`, а не сценой: состав будет меняться вместе с
моделью, и держать его в одном месте с форматированием проще, чем возить по узлам в
редакторе.

Шрифт — Roboto Condensed из `assets/fonts`, переменный: начертание задаётся весом, файл
один. Узкий выбран не для красоты — в панель влезает вдвое больше, а цифры выстраиваются
столбиком. У каждого показателя свой цвет значка: так их различают краем глаза, не
вчитываясь в число.

Фон рисует `scenes/ui/topbar.gdshader`: вертикальный градиент, светлая кромка сверху,
тёмная снизу и едва заметное зерно — без него на широком градиенте видны полосы. Флаг
вырезается в круг шейдером `flag.gdshader`, а не заранее обрезанной картинкой: иначе для
каждой страны понадобился бы свой файл.

Место под каждое число задано шириной, `Metric.Create(..., width)`: раньше ряд стоял по
тексту и на каждой смене цифр весь центр панели дёргался вбок.

## Флаг в панели

Кружок в 40 пикселей, `TopBar.FlagSize`, — крупнее панели, свисает из-под неё. Занимает в
ряду только свою ширину: будь высокой и сама подставка, ряд показателей съехал бы вниз.

Картинка растеризуется в `TopBar.FlagTexture` через `Image.LoadSvgFromBuffer`, а не берётся
у импортёра: тот делает из SVG полотнище в тысячу пикселей, и в кружке остаётся каша. Здесь
запас вчетверо от показа плюс мипмапы. Размер `TextureRect` ставится **после** `AddChild` —
до него он подгоняется под картинку.

Шейдер получает `aspect` — настоящие пропорции полотнища, и вырезает круг из середины, а не
из растянутого в квадрат флага. Край считается через `fwidth`, а не по пикселям текстуры:
текстура вчетверо крупнее показа, и по ней сглаживание выходило в четверть экранного
пикселя, то есть лесенкой.

Для собранной игры в фильтры экспорта надо добавить `*.svg`: сырой файл нужен на месте,
импортированной текстуры мало.

## Боковые вкладки

Слева полоса из шести значков, `scripts/Ui/SideTabs.cs`. Открыта не больше одной панели:
две рядом закрыли бы половину карты. Повторное нажатие на вкладку её закрывает.

| Вкладка | Файл | Что показывает |
|---|---|---|
| Обзор страны | `Panels/OverviewPanel.cs` | люди, достаток, производство, эффективность, деньги |
| Товары | `Panels/GoodsPanel.cs` | 32 строки: выпуск, заказ, склад, цена, куда ушла от старта |
| Промышленность | `Panels/IndustryPanel.cs` | приоритеты отраслей, стройка, здания по типам |
| Торговля | `Panels/TradePanel.cs` | ввоз, вывоз, транзит, доступ к рынкам, запреты по товарам |
| Финансы | `Panels/FinancePanel.cs` | казна, резервы, долг, ключевая ставка, эмиссия, отказ платить |
| Политика | `Panels/PoliticsPanel.cs` | блок, отношения со всеми странами, заморозка чужих резервов |

Общая рама у всех одна — `SidePanel`: шапка со значком и крестиком, прокручиваемое тело,
`Stat`, `Gauge`, `Section` и `Note` для наполнения. Числа пересчитываются четырежды в
секунду и только у открытой панели: сутки идут за секунду, каждый кадр пересобирать
таблицу на сорок строк незачем.

Таблица `scripts/Ui/Table.cs` сортируется щелчком по заголовку, второй щелчок
переворачивает порядок. Сортировка идёт по числу `Cell.Order`, а не по подписи: «1.2M» и
«900K» строками сравниваются неверно. У равных ключей сравниваются подписи — так столбец
с названиями упорядочивается по алфавиту. Узлы строк переиспользуются между обновлениями.

## Графики и полосы

Панели не должны быть колонкой цифр: по одному числу не видно, стало лучше или хуже.

`scripts/Sim/History.cs` — узел, который раз в сутки снимает десяток величин и держит их
за десять лет. Подписан на `GameLoop.Ticked`, поэтому точки появляются и при обычном ходе
времени, и при прокрутке партии для снимков.

У графика бывает переключатель отрезка — `Chart.Ranged()`: неделя, месяц, год, всё время.
Отдельной кнопки «день» нет: точка на ряду и есть день, из одной точки графика не выйдет.

`scripts/Ui/Chart.cs` рисует линии вручную в `_Draw`: узлов на две тысячи точек не
напасёшься. Ряды в одном графике делят шкалу, поэтому вместе кладут только сравнимое —
вывоз с ввозом, но не ВВП с инфляцией. Ниже нуля шкала не опускается, если ряд туда не
заходит: «−262 млрд» под графиком казны читается как долг, которого нет.

`scripts/Ui/Bars.cs` — горизонтальные полосы со значком и числом. Длина считается от
наибольшего в наборе, а не от суммы: сравнивают здесь соседей, а не доли целого.

| Панель | Что нарисовано |
|---|---|
| Обзор | ВВП, уровень цен, занятость с загрузкой; полосы занятости по отраслям |
| Товары | полосы восьми крупнейших производств |
| Промышленность | полосы предприятий по отраслям |
| Торговля | вывоз с ввозом на одном графике; что ввозим и что вывозим полосами |
| Финансы | казна с долгом на одном графике; резервы по эмитентам полосами |
| Политика | сколько стран в каждом блоке |

У каждого раздела свой значок, `Ui.Section(title, icon)`: по нему раздел находят
прокруткой, не вчитываясь в подписи.

Полоса прокрутки рисуется поверх содержимого, а не рядом с ним, поэтому место ей отводится
отступом изнутри — иначе она режет правую колонку чисел.

## Окно производства

`scripts/Ui/ResourceWindow.cs`, во весь экран, седьмая кнопка в полосе вкладок. Панелью
его не сделать: нужны сразу три колонки, а в четыреста пикселей боковой панели они не
встают. Закрывается крестиком или клавишей Esc.

Слева сетка из тридцати двух круглых плашек, `scenes/ui/badge.gdshader`: выпуклый кружок
в цвет товара со значком поверх. Цвет у каждого товара свой, `Names.ColourOf(GoodType)` —
в сетке различают не значок, а пятно, поэтому сырьё землистое, переделы стальные,
потребление тёплое, военное красное. Под плашкой число, и шесть кнопок под сеткой
переключают, что это за число: выпуск, заказ, склад, цена, нехватка или залежи.

Посередине — круг владельцев предприятий, которые делают этот товар **в нашей стране**,
`scripts/Ui/Pie.cs`. Дольки рисуются веером треугольников: готового сектора в Godot нет,
а цвет задаётся по вершинам — к середине темнее, к ободу светлее.

Пока в круге почти всегда одна долька: своих предприятий у частника и у чужих стран в
модели нет, всё производство государственное. Второй владелец появляется там, где граница
разрезала область: `Region.BuildingsOf(тип, страна)` делит постройки по доле ячеек, и часть
их числится за соседом. Круг заведён под будущие компании и чужую собственность, а не под
сегодняшнее состояние.

Место под подписи владельцев задано шириной: у товара, которого страна не делает, подписей
нет, и без этого круг съезжал вбок при каждом переключении.

Мировые доли никуда не делись — они рядом полосами, «Кто производит в мире». Ниже вложение
и кто больше всех этот товар вывозит и ввозит.

Под выбором завода — рецепт: слева вход, справа выход, между ними стрелка с бегущими
уголками, `scripts/Ui/Flowline.cs`. Уголки бегут, потому что неподвижная стрелка на такой
схеме читается просто как разделитель, а не как работа. Обе стороны прижаты к середине по
высоте: стрелка должна идти между списками, а не мимо них, когда слева четыре строки, а
справа одна.

Товары в рецептах идут по переделам — по порядку `GoodType`: сырьё, потом электричество,
потом обработанное. Раньше сортировка шла по величине, и в одном рецепте электричество
оказывалось первым, в другом последним.

Блок «кто больше всех возит» у услуг не показывается вовсе: через границу их не возят, и
пустые полосы там только сбивали с толку. У остальных товаров пустая сторона пишет «никто
не возит» — пустое место читается как поломка, а «никого» как ответ.

Справа сведения по товару и, если товар вообще залегает в земле, число месторождений в
стране. Что залегает, а что нет, берётся из `BuildingInfo.RequiresDeposit`: сталь не копают,
и строка о залежах у неё только сбивала с толку.

Колонки стоят по краям: левая у левого края, правая у правого, а середина занимает всё,
что между ними, и держит содержимое по центру двумя распорками. Крестик — красный, в самом
углу окна, а не внутри колонки.

Задник рисует `scenes/ui/curtain.gdshader`: тёмная основа, три слоя медленных пятен,
штриховка через строку, мягкий свет за средней колонкой, виньетка и силуэт производства
понизу — корпуса, трубы и дым над ними. Картинки нет, всё считается в шейдере: фотографию
подходящего завода в игру не положишь, а пустое тёмное поле выглядит незаконченным.

Числа пересчитываются четырежды в секунду **и по каждому тику**, `GameLoop.Ticked`: иначе
цена постройки висела старой до следующего касания мышью.

## Вложение в производство

Кнопка «Вложить» — настоящее действие, а не украшение. `Simulation.Invest(страна, тип,
деньги)` снимает сумму с казны, кладёт её в кошелёк стройки и назначает, что строить.
Дальше всё идёт общим путём: те же материалы, те же руки, та же цена. Обходится только
выбор по прибыли — `PlanBuilds` спрашивает сперва заказ, а потом уже `BestBuild`.

Вкладывают **деньгами, а не штуками**: половина цены завода — тоже вложение, она просто
полежит в кошельке стройки, пока страна не доложит своё и не наберётся на целый. Поэтому
заказ держится не счётчиком построек, а остатком вложенного: `(тип, сколько денег ещё не
потрачено)`. Число за тик режется общим потолком `MaxBuildsPerTick`, а не заказом — иначе
вложение меньше цены одного здания намертво блокировало бы стройку.

Под шкалой вложений — прогноз по каждому материалу постройки: с какой скоростью его цена
идёт сейчас и на сколько её ускорит эта стройка.

Первая попытка была бинарной: `SafeToBuild` считал сумму, при которой цены **вообще не
двинутся**, — то есть при которой на складе останется ровно сорокадневный запас. На деле
засечка всегда стояла на нуле или пропадала: склад почти никогда не держит ровно норму,
цены и так уже куда-то идут, и порога «не двинутся» просто не существует.

Полезен не порог, а величина. `Simulation.PaceOf` говорит, с какой скоростью цена товара
идёт сейчас, а `PriceLift` — на сколько эта скорость вырастет, если добавить к спросу
столько-то. `OrderLift` берёт худший материал заказа. Подпись читается так:

> Сильнее всего заденет стройматериалы: сейчас −1.2% в день, эта стройка добавит +0.8%.
> Довезут из-за границы, дорога добавит 18% к мировой цене.

Засечка на шкале была и вторая попытка — сумма, на которой худший материал начинает
ускоряться на процент в день. Её тоже убрали: точка на полосе не говорит, что именно
подорожает и насколько, а строки с числами говорят сразу и про все материалы. Пока ползунок
на нуле, прогноз считает для всей казны: иначе он молчит как раз тогда, когда хочется
прикинуть размах. Под списком остаётся одна строка — довезут ли худший материал из-за
границы и во что обойдётся дорога; услуги не возят вовсе.

## Куда уходит товар

В окне производства под долями стран — «Куда уходит у нас»: какие заводы просят этот товар,
сколько берёт стройка и сколько население. Считается по заказу, а не по съеденному: съедено
— это то, что нашлось на складе, и при нехватке все доли ужимаются разом, будто её и не
было.

## Казна: доходы и расходы

В панели финансов под остатком — откуда он взялся: продажи населению приходят, зарплаты,
накопление на стройку и доля владельцев уходят. Это не украшение: без разбивки казна
выглядит стоящей на месте, хотя через неё за день проходит весь оборот страны.

Сама казна — оборотная касса, а не запас на чёрный день. Всё, что за день выручено сверх
зарплат, тем же днём расходится: четверть выпуска в кошелёк стройки, остальное владельцам
предприятий. Владельцы — такие же люди, и деньги возвращаются в те же кошельки.

## Заявка на заём

Государство игрока само в долг не лезет и само не строит: `Simulation.HandsOff` — это
страна, за которую модель не решает. Строит она только заказанное игроком, а занимает
только по его заявке.

В панели финансов появился раздел «Занять»: ставите сумму, и `Simulation.OffersFor`
показывает, кто готов её дать и под какой процент. Считается всё тем же правилом, что и
мировой аукцион `CreditMarket.Settle`: ставка растёт с долговой нагрузкой, идёт за ключевой
ставкой кредитора и зависит от отношений — враждебные не дадут ни под какой процент.
Показанная ставка обязана совпасть с той, по которой заём и возьмут, поэтому формула одна
на оба места.

Заказ на много зданий растягивается на дни: за тик стройка берёт не больше трети склада по
каждому материалу, `Simulation.CanRaisePerTick`, и каждый следующий день платит уже
подорожавшую цену. Сколько страна поднимет за день, написано рядом с суммой.

Под ползунком видно, на сколько предприятий хватит суммы **по нынешней цене**, цена одного
и **из чего она складывается сейчас**: каждый товар из `BuildCost` по нынешней цене плюс работа строителей,
`Simulation.BuildWageOf`. Цена меняется вместе с ценами на материалы, и разбор показывает,
за что именно.

Число предприятий — именно оценка, и так и написано: деньги лежат в кошельке стройки и
тратятся по цене того дня, когда здание встанет. Пока идёт большой заказ, материалы
дорожают, и выйдет меньше, чем показано на входе.

## Рычаги

Всё, чем игрок правит модель, собрано в двух панелях и работает через существующие поля:

| Рычаг | Где | Что читает тик |
|---|---|---|
| Приоритет отрасли | Промышленность | `Priorities.SetWeight` |
| Ключевая ставка | Финансы | `Country.KeyRate` |
| Потолок заимствования | Финансы | `Country.MaxBorrowRate` |
| Доля труда в выручке | Финансы | `Country.LabourShare` |
| Печать денег | Финансы | `CentralBank.Emit` |
| Отказ платить | Финансы | `Debt.Default` + `DefaultedOnDay` |
| Запрет товара | Торговля | `TradeAccess.Block` / `Allow` |
| Отношения | Политика | `Relations.Set` + пересчёт маршрутов |
| Заморозка резервов | Политика | `Reserves.Freeze` |

Печать и отказ платить модель обычно делает сама; кнопки нужны, чтобы посмотреть, что
будет, если сделать это раньше.

## Тревоги

`scripts/Ui/AlertBar.cs`, девять значков в верхней панели, правее полосы вкладок: у самого
края они читались как её продолжение. Каждый сидит на плашке своего цвета — одного оттенка
значка на тёмной панели не хватало, чтобы заметить. Горящий медленно дышит — неподвижный
красный значок глаз перестаёт замечать через минуту. Щелчок открывает нужную вкладку.

Первые шесть — это состояния, и ничего нового они не считают: нехватка рук это
`JobsIn > EmployedIn`, простой — `LoadIn < Load.Full`, дальше `ShortOf`, отрицательная
казна, `FrozenBy` и `DefaultedOnDay`.

Последние три — **перемены**, ради которых на панель и смотрят. Считаются сравнением с тем,
что было месяц назад, `History.Month`:

| Тревога | Когда горит |
|---|---|
| Товар резко подорожал | цена хоть одного товара ушла в полтора раза, `History.Jump` |
| Цены разгоняются | уровень цен вырос больше чем на пять пунктов за месяц |
| Валюта слабеет | курс ушёл больше чем на пятнадцать процентов |

Для этого история держит не только ряды по дням, но и кольцо снимков цен за последний
месяц — по одному на день, тридцать снимков на тридцать два товара.

В подсказке у каждой тревоги есть раздел «Что можно сделать» со ссылками на нужные рычаги,
а у перемен ещё и строка с подробностью: какой именно товар подорожал и во сколько раз. Она
дописывается к статье на месте — `PopoverStack.Open(..., extra)` и `HoverProbe.Extra`:
статья в словаре объясняет беду вообще, а строка говорит, что происходит сейчас.

## Карточка по щелчку

`scripts/Ui/SelectionPanel.cs` в правом нижнем углу. Щелчок ловит сама карта,
`WorldMapView.Clicked`: скрытая панель событий ввода не получает, а прятаться ей надо.
Щелчок отделяется от перетаскивания по пройденному пути — карту таскают той же левой
кнопкой. Точка берётся из события, а не из положения курсора, иначе проверочный снимок с
подставленным щелчком не работает.

## Инфляция и цены

На виду держится **годовая** инфляция, `History.Yearly()`: уровень цен сегодня против
уровня год назад. Уровень «с начала партии» за пять лет уходит в сотни процентов и
перестаёт что-либо значить — он остался во вкладке обзора отдельной строкой и на графике.
Пока не набралось трёх месяцев, показывается просто рост с начала партии: на второй день
приведение к году возводило дневное движение в триста шестьдесят пятую степень, и процент
превращался в тысячи процентов годовых. Это и был всплеск инфляции в первые секунды —
наполовину он шёл отсюда, наполовину из самой модели, см. `09-reality-check.md`.

В таблице товаров столбец «к старту» заменён на **«к миру»** — наша цена к среднемировой.
Прежний был не только бесполезен, но и сломан: цены упираются в границу коридора
`Prices.MaxSwingTimes`, и после этого столбец навсегда показывал ×100. Мировая цена —
`GameWorld.Market.Prices`, средняя из настоящих сделок между странами; у услуг её нет,
потому что их не возят, и там стоит прочерк.

Берётся она не напрямую, а через `Simulation.WorldPriceIn`: мировая цена живёт в мировой
мере, наша — в своих деньгах, и без перевода по курсу столбец сравнивал рубли с непонятно
чем. Сперва он и сравнивал: у России стройматериалы показывали ×375 — на деле там была не
дороговизна, а разные линейки.

## Деньги подписываются валютой страны

`Fmt.Cash` ставит знак валюты игрока — рубль, иену, евро, — а `Fmt.World` доллар. Делить
пришлось: у каждой страны свои деньги, но резервы, внешний долг и внешняя торговля у всех
считаются в одной мере, и подписывать их рублём было бы враньём.

Знак берётся из `Country.Currency`, а тот — из `data/economy/currencies.json`, который
собирает `tools/fetch-rates.mjs`. Ставится один раз при загрузке мира: `Fmt.Symbol`.

## Курс — это индекс, а не рубли за доллар

Уже нет: курс берётся из жизни, `Country.ExchangeRate` стартует с настоящего значения
2020 года — 72.1 у рубля, 6.9 у юаня, 107 у иены. Ниже осталось описание того, как было.

`Country.ExchangeRate` начинается с единицы у всех и показывает, насколько валюта ушла от
начала партии. Настоящего курса там нет и быть пока не может: цены всех стран в модели
считаются **в одной единице**, и курс участвует в переводе местной цены в мировую —
`Simulation.Trade`. Поставить России 72 значит объявить её товары в семьдесят два раза
дешевле мировых и сломать всю торговлю. Настоящий курс появится тогда, когда у каждой
страны будут свои деньги и свои цены.

Поэтому подписи честные: «курс валюты к старту», и значение пишется с крестиком — ×0.81.

Тянут курс три силы разом, каждая не больше двух процентов за сутки: паритет цен, сальдо
платёжного баланса и достаточность резервов. Поэтому одна инфляция двигает его медленно —
две другие силы могут тянуть в обратную сторону.

## Ctrl и Shift множат действие

Везде, где кнопка меняет число шагом, Ctrl делает шаг вдесятеро, а Shift — всотеро,
`Ui.Louder()`. Ставку от нуля до тридцати процентов шагом в четверть пункта иначе крутить
сто двадцать раз. Работает у всех ступенек, у печати денег и у правки отношений.

## Карточка товара

Везде, где товар назван словом, наведение показывает о нём карточку, `scripts/Ui/GoodCard.cs`:
тот же кружок, что и в сетке окна производства, отношение к мировой цене плашкой, четыре
числа сеткой, цена за год графиком, выпуск против заказа вторым графиком и рецепт
значками. Текстом это читается вдвое дольше.

Два графика, а не один: по цене видно, что происходит, но не отчего. Выпуск и заказ рядом
отвечают на это сразу — товара стали меньше делать или больше просить.

Для этого подсказка научилась показывать не только статью, но и собранный виджет:
`Popover.Create(source, key, body)` и `HoverProbe.Card`. Виджет рисует и заголовок, и всё
остальное сам, поэтому рамке о нём знать нечего.

Тем же способом сделаны подсказки-графики, `TrendCard`. Собраны они в одном месте,
`scripts/Ui/Trends.cs`: один и тот же показатель висит и в верхней панели, и в боковой, и
подпись с цветом у него должны быть те же самые.

| Где | Что на графике |
|---|---|
| Население, рабочая сила | за год |
| Занятость, загрузка предприятий | за год, в процентах |
| ВВП, казна, внешний долг, денежная масса | за год, в деньгах |
| Предприятия | за год, штуками — это и есть мощности |
| Курс валюты | курс за год |
| Инфляция | **понедельная**: годовой разгон размазан по всему году и не виден |
| Цена товара | за год |
| Выпуск и заказ товара | за год, двумя рядами |
| Наша цена к мировой | отношение за год |

Для этого история держит кольца на год: наши цены, мировые цены, склад, заказ и выпуск по
каждому товару. Тридцать два числа в день на кольцо — памяти не жалко, а без истории не
видно, что дорожает и отчего.

## У графика есть шкала

Раньше под полем стояли два числа — низ слева, верх справа, — и по ним приходилось
догадываться, где проходит середина. Теперь слева от поля обычная шкала: три-четыре
подписи у своих линий, `Chart.Plot`.

Шаг берётся круглый — `Chart.Step` выбирает из ряда 1, 2, 2.5, 5 на своём порядке, — а
делений выходит сколько выйдет. Наоборот не годится: с жёсткими четырьмя делениями шкала
занятости растягивалась до двухсот процентов при настоящих ста восьми. Больше четырёх
делений не рисуем: поле высотой в восемьдесят точек, и на шести подписи слипаются.

Ключом служит `good:<товар>` — иначе подсказка не заметила бы, что мышь переехала на другой
товар.

Карточка держится не готовым виджетом, а сборщиком: `Popover.Restock` дважды в секунду
пересобирает её заново. Без этого висящий график замирал на том дне, когда его открыли, и
оживал, только если увести мышь и навести снова.

В карточке есть строка **отчего цена идёт**. Догадок там нет: цена в модели ходит ровно от
покрытия склада, а общий уровень тянут деньги, и обе причины названы прямо. Недельные
перемены склада и заказа говорят, которая сторона сдвинулась:

> Дешевеет на 1.0% в день — запаса больше нормы. За неделю склад упал на 11.4%.
> Сверх этого деньги тянут все цены страны вверх на 0.6% в день.

Скорость даёт `Simulation.PaceOf`, общий сдвиг — `LevelPushOf`: сколько якорь двинул
уровень на прошлом тике.

Карточка есть в рецепте, в разборе цены постройки, в полосах крупнейших производств и в
таблицах вкладок «Товары» и «Торговля»: `Table.Create` и `Bars.Create` принимают стопку
подсказок и функцию, отдающую статью по номеру строки.

Строки при этом **переиспользуются, а не пересобираются**. Пересозданная строка утаскивает
подсказку за собой: её источник становится недействительным, и она гаснет в тот же кадр.
Товар строки держится в метаданных узла — `SetMeta("good", ...)`.

## Ничто не должно дёргаться

Интерфейс обновляется четырежды в секунду, и любой элемент, который меряет себя по тексту,
на каждой смене числа сдвигает соседей. Правила против этого:

- у числа, которое меняется, задана ширина — `Ui.Number(текст, размер, цвет, ширина)`;
- у кнопки с меняющейся подписью задана ширина и включён `ClipText` — `Ui.Act(..., width)`;
  а лучше подпись не менять вовсе: «Вложить» осталось «Вложить», а «хватит на 3.4
  предприятия» переехало в отдельную строку;
- у заголовков таблицы `ClipText` включён всегда: иначе стрелка сортировки расширяет
  столбец, и вся таблица уезжает вбок;
- подписи рядов на графике держат свою ширину, иначе при смене числа соседняя подпись
  ездит вместе с первой;
- длинные перечни режутся по месту, а не шириной подписи: список заморозивших резервы
  показывает троих и «и ещё N»;
- длинные пояснения переносятся по словам и знают свою ширину. Без этого одна длинная
  строка растягивала колонку окна шире её собственного минимума, и при смене текста —
  например после нажатия «Вложить» — вся середина окна сужалась рывком.

Цифры везде моноширинные, `Skin.Digits()`: у обычных начертаний ширина цифр разная, и
число шевелится, даже стоя на месте.

## Цвет не бывает ровным

Ровная заливка выглядит как кусок пластика, поэтому цвет везде с фактурой:

| Где | Чем |
|---|---|
| Плашки товаров | `badge.gdshader`: свет сверху слева, внутренняя тень у края, блик и зерно |
| Значки на плашках | `icon.gdshader`, `Skin.Glyph(цвет кружка)`: градиент по высоте и обводка |
| Полосы и заполнения | `fill.gdshader`, `Skin.Fill(цвет)`: поперечный градиент, косые полосы, зерно |
| Кнопки | та же заливка за кнопкой плюс скос: светлая кромка сверху, тёмная снизу |
| Дольки круга | кольцевые сектора четырёхугольниками, внутренний край темнее внешнего |
| Заливка под линией графика | цвет по вершинам, книзу гаснет |
| Задник большого окна | `curtain.gdshader` |

Кнопке фон рисует не `StyleBoxFlat` — у него нет градиента, — а отдельный `ColorRect` с
`ShowBehindParent`: он попадает под собственную отрисовку кнопки, поэтому рамка и подпись
остаются сверху. Сама коробка при этом с прозрачным фоном.

Значок красится по светлоте кружка: на тёмном светлый, на светлом тёмный, и всегда с
обводкой. Значки у нас силуэтные, в один цвет, — без градиента и обводки они выглядели
плоской наклейкой, а без выбора по светлоте один чёрный сливался с половиной палитры.

Дольки круга рисуются кольцом из четырёхугольников, а не веером треугольников из середины:
у веера все треугольники делят одну вершину, и цвет по ним растекался пятнами.

## Деньги в подписях

Внутри модель считает деньги **тысячами долларов**: иначе мировой ВВП не влезает в `Money`
с его сотыми долями. Наружу интерфейс показывает доллары — `Fmt.Dollar = 1000`. Пока этого
множителя не было, панель показывала ВВП России как 1.79 млрд вместо 1.79 трлн.

Столбец «к старту» во вкладке товаров — это цена, делённая на цену начала партии. Значение
×0.01 или ×100 означает, что цена упёрлась в границу коридора `Prices.MaxSwingTimes`; то же
самое считает счётный прогон в разделе «Цены и границы коридора».

## Скорость времени

Сутки идут за секунду при обычной скорости. Множители и пауза — справа под панелью,
`scripts/Ui/SpeedBar.cs`; с клавиатуры пробел ставит на паузу и снимает, `1`, `2`, `3`
дают скорости ×1, ×2 и ×4. Пауза помнит, с какой скорости её включили, и возвращает её.

## Подсказки

Наведение на показатель открывает пояснение на русском. В тексте бывают термины — на них
можно навести и получить вторую подсказку, на неё третью и так далее.

Тексты лежат в `data/ui/glossary.json`, а не в коде: их правят чаще, чем логику. Ссылка
на термин пишется как `[[ключ|видимый текст]]`.

Подсказка **не двигается** после открытия и **не гаснет**, пока мышь на ней или на том,
от чего она открыта. Закрываются они с хвоста цепочки в `PopoverStack`, и проверяется это
перебором прямоугольников каждый кадр, а не событиями входа-выхода: между элементами есть
щели в пиксель, и на них события врут. Наведение ловится так же — заодно это единственный
способ проверить подсказку снимком, потому что программно поставленный курсор события
движения не порождает.

Что считать «источником», зависит от глубины. У верхней подсказки это её элемент, и
работает прямоугольник. У вложенной — сам термин, а не строка текста, в которой он стоит:
`Popover.Alive` для неё смотрит на `HotTerm` родителя, который ведут события
`MetaHoverStarted` и `MetaHoverEnded`. Пока этого не было, вторая подсказка висела, пока
мышь оставалась где угодно в первой.

Ставится подсказка **сбоку**, если источник прижат к левому краю экрана, и снизу во всех
остальных случаях, `Popover.PlaceNear`. Вкладки и строки панели стоят слева, и подсказка
под ними закрывала бы то, ради чего её открыли.

Сбоку она стоит **вплотную** к источнику. С зазором курсор, идущий от элемента к
подсказке, успевал побывать вне обоих прямоугольников — и она гасла раньше, чем до неё
доводили.

Родные подсказки Godot со вкладок сняты: `TooltipText` показывался поверх нашей, второй
надписью с названием раздела.

## Названия стран

В `data/map/countries.json` и `regions.json` имена английские: они пришли из Natural Earth
и служат ключом сверки с данными, менять их нельзя. Переводы лежат рядом и читаются
`Names.Of(Country)` и `Names.Region(имя)`:

| Файл | Что в нём | Откуда |
|---|---|---|
| `data/ui/countries-ru.json` | 200 стран по коду ISO | вручную |
| `data/ui/regions-ru.json` | 1550 названий областей | `tools/fetch-region-names.mjs` |
| `data/ui/regions-extra-ru.json` | 63 названия, которых нет в источнике | вручную |

Инструмент качает `ne_10m_admin_1_states_provinces.geojson` и берёт оттуда `name_ru`. Поля
`region`, по которому генератор укрупнял мелкие единицы, Natural Earth не переводит вовсе —
такие названия (Апулия, Бретань, Северная Ирландия, все французские новые регионы) дописаны
руками в `regions-extra-ru.json`. Чего не хватит после следующей перенарезки, инструмент
перечислит в конце прогона.

## Флаги

`assets/flags/<ISO3>.svg`, 255 штук: все коды ISO 3166-1 плюс непризнанные с нашей карты.
Скачиваются `tools/fetch-flags.mjs`. Берутся все, а не только наши двести: за партию
страны появляются и исчезают, и флаг должен найтись для любой.

## Снимок экрана для проверки

```
godot --path . -- --shot=C:/tmp/ui.png --shot-frame=90 --shot-days=730 --shot-tab=1 --shot-mouse=250,164
```

| Ключ | Что делает |
|---|---|
| `--shot-days=N` | прокручивает партию на N суток разом |
| `--shot-tab=N` | открывает вкладку с номером |
| `--shot-click=x,y` | щёлкает по карте, чтобы снять карточку страны |
| `--shot-mouse=x,y;x,y` | ведёт курсор по точкам, по восемь кадров на каждую |
| `--shot-window` | открывает окно производства |
| `--shot-good=N` | выбирает в нём товар с этим номером |
| `--shot-focus=x,y,zoom` | наводит камеру |

`--shot-days` крутит по двадцать суток за кадр, а не все разом. Сотня тиков в одном кадре
вешает его на секунды, а зависший кадр Windows считает отказом видеодрайвера и сбрасывает
его вместе с игрой — так и вышло дважды. По той же причине кадры ограничены шестьюдесятью
в секунду: раньше инструмент выключал вертикальную синхронизацию ради замера.

Отдельная ловушка того же рода — узлы. Цикл «пока детей больше нужного — QueueFree»
крутится вечно: `QueueFree` удаляет в конце кадра, и счётчик детей внутри цикла не
меняется. Обрезать список узлов надо через `Ui.Trim`, который сперва вынимает ребёнка из
дерева и только потом освобождает.

Порядок жёсткий: прокрутка, вкладка, щелчок, потом курсор. Иначе наводиться не на что —
мышь успевает пройти по точкам до того, как панель открылась. Несколько точек в
`--shot-mouse` нужны, чтобы проверить вложенные подсказки: навести на термин и уйти с него,
оставаясь в первой подсказке.

`--shot-days` нужен почти всегда: сутки идут за секунду, и без прокрутки панель показывает
четвёртый день партии, где половина чисел ещё нули. `--shot-mouse` шлёт событие движения
отдельно — без него подсказки не открыть.
