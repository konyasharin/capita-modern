# Интерфейс

## Верхняя панель

Занимает всю ширину, высотой 34 пикселя. Слева пока пусто — там будут кнопки разделов.
Посередине показатели страны игрока, справа дата.

| Показатель | Откуда берётся |
|---|---|
| Население | `GameWorld.PopulationOf` |
| Валовой продукт | `Simulation.ValueAddedOf` в постоянных ценах, на год |
| Мощности | сумма `Region.BuildingsCount` по стране |
| Инфляция | `Simulation.PriceLevelOf` против начала партии |
| Казна | `Treasury.Balance` |

Собирается кодом в `scripts/Ui/TopBar.cs`, а не сценой: состав будет меняться вместе с
моделью, и держать его в одном месте с форматированием проще, чем возить по узлам в
редакторе.

Шрифт — Roboto Condensed из `assets/fonts`, переменный: начертание задаётся весом, файл
один. Узкий выбран не для красоты — в панель влезает вдвое больше, а цифры выстраиваются
столбиком. У каждого показателя свой цвет значка: так их различают краем глаза, не
вчитываясь в число.

Фон рисует `scenes/ui/topbar.gdshader`: вертикальный градиент, светлая кромка сверху,
тёмная снизу и едва заметное зерно — без него на широком градиенте видны полосы. Флаг
вырезается в круг шейдером `flag.gdshader`, а не заранее обрезанной картинкой: иначе для
каждой страны понадобился бы свой файл.

Место под каждое число задано шириной, `Metric.Create(..., width)`: раньше ряд стоял по
тексту и на каждой смене цифр весь центр панели дёргался вбок.

## Флаг в панели

Кружок в 40 пикселей, `TopBar.FlagSize`, — крупнее панели, свисает из-под неё. Занимает в
ряду только свою ширину: будь высокой и сама подставка, ряд показателей съехал бы вниз.

Картинка растеризуется в `TopBar.FlagTexture` через `Image.LoadSvgFromBuffer`, а не берётся
у импортёра: тот делает из SVG полотнище в тысячу пикселей, и в кружке остаётся каша. Здесь
запас вчетверо от показа плюс мипмапы. Размер `TextureRect` ставится **после** `AddChild` —
до него он подгоняется под картинку.

Шейдер получает `aspect` — настоящие пропорции полотнища, и вырезает круг из середины, а не
из растянутого в квадрат флага. Край считается через `fwidth`, а не по пикселям текстуры:
текстура вчетверо крупнее показа, и по ней сглаживание выходило в четверть экранного
пикселя, то есть лесенкой.

Для собранной игры в фильтры экспорта надо добавить `*.svg`: сырой файл нужен на месте,
импортированной текстуры мало.

## Боковые вкладки

Слева полоса из шести значков, `scripts/Ui/SideTabs.cs`. Открыта не больше одной панели:
две рядом закрыли бы половину карты. Повторное нажатие на вкладку её закрывает.

| Вкладка | Файл | Что показывает |
|---|---|---|
| Обзор страны | `Panels/OverviewPanel.cs` | люди, достаток, производство, эффективность, деньги |
| Товары | `Panels/GoodsPanel.cs` | 32 строки: выпуск, заказ, склад, цена, куда ушла от старта |
| Промышленность | `Panels/IndustryPanel.cs` | приоритеты отраслей, стройка, здания по типам |
| Торговля | `Panels/TradePanel.cs` | ввоз, вывоз, транзит, доступ к рынкам, запреты по товарам |
| Финансы | `Panels/FinancePanel.cs` | казна, резервы, долг, ключевая ставка, эмиссия, отказ платить |
| Политика | `Panels/PoliticsPanel.cs` | блок, отношения со всеми странами, заморозка чужих резервов |

Общая рама у всех одна — `SidePanel`: шапка со значком и крестиком, прокручиваемое тело,
`Stat`, `Gauge`, `Section` и `Note` для наполнения. Числа пересчитываются четырежды в
секунду и только у открытой панели: сутки идут за секунду, каждый кадр пересобирать
таблицу на сорок строк незачем.

Таблица `scripts/Ui/Table.cs` сортируется щелчком по заголовку, второй щелчок
переворачивает порядок. Сортировка идёт по числу `Cell.Order`, а не по подписи: «1.2M» и
«900K» строками сравниваются неверно. У равных ключей сравниваются подписи — так столбец
с названиями упорядочивается по алфавиту. Узлы строк переиспользуются между обновлениями.

## Графики и полосы

Панели не должны быть колонкой цифр: по одному числу не видно, стало лучше или хуже.

`scripts/Sim/History.cs` — узел, который раз в сутки снимает десяток величин и держит их
за десять лет. Подписан на `GameLoop.Ticked`, поэтому точки появляются и при обычном ходе
времени, и при прокрутке партии для снимков.

`scripts/Ui/Chart.cs` рисует линии вручную в `_Draw`: узлов на две тысячи точек не
напасёшься. Ряды в одном графике делят шкалу, поэтому вместе кладут только сравнимое —
вывоз с ввозом, но не ВВП с инфляцией. Ниже нуля шкала не опускается, если ряд туда не
заходит: «−262 млрд» под графиком казны читается как долг, которого нет.

`scripts/Ui/Bars.cs` — горизонтальные полосы со значком и числом. Длина считается от
наибольшего в наборе, а не от суммы: сравнивают здесь соседей, а не доли целого.

| Панель | Что нарисовано |
|---|---|
| Обзор | ВВП, уровень цен, занятость с загрузкой; полосы занятости по отраслям |
| Товары | полосы восьми крупнейших производств |
| Промышленность | полосы предприятий по отраслям |
| Торговля | вывоз с ввозом на одном графике; что ввозим и что вывозим полосами |
| Финансы | казна с долгом на одном графике; резервы по эмитентам полосами |
| Политика | сколько стран в каждом блоке |

У каждого раздела свой значок, `Ui.Section(title, icon)`: по нему раздел находят
прокруткой, не вчитываясь в подписи.

Полоса прокрутки рисуется поверх содержимого, а не рядом с ним, поэтому место ей отводится
отступом изнутри — иначе она режет правую колонку чисел.

## Окно производства

`scripts/Ui/ResourceWindow.cs`, во весь экран, седьмая кнопка в полосе вкладок. Панелью
его не сделать: нужны сразу три колонки, а в четыреста пикселей боковой панели они не
встают. Закрывается крестиком или клавишей Esc.

Слева сетка из тридцати двух круглых плашек, `scenes/ui/badge.gdshader`: выпуклый кружок
в цвет товара со значком поверх. Цвет у каждого товара свой, `Names.ColourOf(GoodType)` —
в сетке различают не значок, а пятно, поэтому сырьё землистое, переделы стальные,
потребление тёплое, военное красное. Под плашкой число, и шесть кнопок под сеткой
переключают, что это за число: выпуск, заказ, склад, цена, нехватка или залежи.

Посередине — круг долей стран в мировом выпуске выбранного товара, `scripts/Ui/Pie.cs`.
Дольки рисуются веером треугольников: готового сектора в Godot нет. Цвета берутся из
своего набора, а не из оттенков цвета товара — оттенки сливались в кашу; страна игрока
всегда белая, её долю ищут первой. Ниже вложение, ещё ниже — кто больше всех этот товар
вывозит и ввозит.

Справа сведения по товару, что нужно для его выпуска и число месторождений в стране.

Задник рисует `scenes/ui/curtain.gdshader`: тёмная основа, три слоя медленных пятен,
штриховка через строку, мягкий свет за средней колонкой и виньетка.

## Вложение в производство

Кнопка «Вложить» — настоящее действие, а не украшение. `Simulation.Invest(страна, тип,
сколько, деньги)` снимает сумму с казны, кладёт её в кошелёк стройки и назначает, что
строить. Дальше всё идёт общим путём: те же материалы, те же руки, та же цена. Обходится
только выбор по прибыли — `PlanBuilds` спрашивает сперва заказ, а потом уже `BestBuild`.

Заказ живёт, пока не выполнен: за один тик столько не построить. Что осталось, видно под
кнопкой.

## Рычаги

Всё, чем игрок правит модель, собрано в двух панелях и работает через существующие поля:

| Рычаг | Где | Что читает тик |
|---|---|---|
| Приоритет отрасли | Промышленность | `Priorities.SetWeight` |
| Ключевая ставка | Финансы | `Country.KeyRate` |
| Потолок заимствования | Финансы | `Country.MaxBorrowRate` |
| Доля труда в выручке | Финансы | `Country.LabourShare` |
| Печать денег | Финансы | `CentralBank.Emit` |
| Отказ платить | Финансы | `Debt.Default` + `DefaultedOnDay` |
| Запрет товара | Торговля | `TradeAccess.Block` / `Allow` |
| Отношения | Политика | `Relations.Set` + пересчёт маршрутов |
| Заморозка резервов | Политика | `Reserves.Freeze` |

Печать и отказ платить модель обычно делает сама; кнопки нужны, чтобы посмотреть, что
будет, если сделать это раньше.

## Тревоги

`scripts/Ui/AlertBar.cs`, шесть значков в верхней панели, правее полосы вкладок: у самого
края они читались как её продолжение. Каждый сидит на плашке своего цвета — одного оттенка
значка на тёмной панели не хватало, чтобы заметить. Горящий медленно
дышит — неподвижный красный значок глаз перестаёт замечать через минуту. Щелчок открывает
нужную вкладку. Ничего нового не считается: нехватка рук это `JobsIn > EmployedIn`,
простой — `LoadIn < Load.Full`, дальше `ShortOf`, отрицательная казна, `FrozenBy` и
`DefaultedOnDay`.

## Карточка по щелчку

`scripts/Ui/SelectionPanel.cs` в правом нижнем углу. Щелчок ловит сама карта,
`WorldMapView.Clicked`: скрытая панель событий ввода не получает, а прятаться ей надо.
Щелчок отделяется от перетаскивания по пройденному пути — карту таскают той же левой
кнопкой. Точка берётся из события, а не из положения курсора, иначе проверочный снимок с
подставленным щелчком не работает.

## Деньги в подписях

Внутри модель считает деньги **тысячами долларов**: иначе мировой ВВП не влезает в `Money`
с его сотыми долями. Наружу интерфейс показывает доллары — `Fmt.Dollar = 1000`. Пока этого
множителя не было, панель показывала ВВП России как 1.79 млрд вместо 1.79 трлн.

Столбец «к старту» во вкладке товаров — это цена, делённая на цену начала партии. Значение
×0.01 или ×100 означает, что цена упёрлась в границу коридора `Prices.MaxSwingTimes`; то же
самое считает счётный прогон в разделе «Цены и границы коридора».

## Скорость времени

Сутки идут за секунду при обычной скорости. Множители и пауза — справа под панелью,
`scripts/Ui/SpeedBar.cs`; с клавиатуры пробел ставит на паузу и снимает, `1`, `2`, `3`
дают скорости ×1, ×2 и ×4. Пауза помнит, с какой скорости её включили, и возвращает её.

## Подсказки

Наведение на показатель открывает пояснение на русском. В тексте бывают термины — на них
можно навести и получить вторую подсказку, на неё третью и так далее.

Тексты лежат в `data/ui/glossary.json`, а не в коде: их правят чаще, чем логику. Ссылка
на термин пишется как `[[ключ|видимый текст]]`.

Подсказка **не двигается** после открытия и **не гаснет**, пока мышь на ней или на том,
от чего она открыта. Закрываются они с хвоста цепочки в `PopoverStack`, и проверяется это
перебором прямоугольников каждый кадр, а не событиями входа-выхода: между элементами есть
щели в пиксель, и на них события врут. Наведение ловится так же — заодно это единственный
способ проверить подсказку снимком, потому что программно поставленный курсор события
движения не порождает.

Что считать «источником», зависит от глубины. У верхней подсказки это её элемент, и
работает прямоугольник. У вложенной — сам термин, а не строка текста, в которой он стоит:
`Popover.Alive` для неё смотрит на `HotTerm` родителя, который ведут события
`MetaHoverStarted` и `MetaHoverEnded`. Пока этого не было, вторая подсказка висела, пока
мышь оставалась где угодно в первой.

Ставится подсказка **сбоку**, если источник прижат к левому краю экрана, и снизу во всех
остальных случаях, `Popover.PlaceNear`. Вкладки и строки панели стоят слева, и подсказка
под ними закрывала бы то, ради чего её открыли.

## Названия стран

В `data/map/countries.json` имена английские: они пришли из Natural Earth и служат ключом
сверки с данными, менять их нельзя. Перевод лежит рядом, `data/ui/countries-ru.json`, все
двести кодов; читает его `Names.Of(Country)`. Названия областей остались английскими —
их 1616, и берутся они из той же нарезки Natural Earth.

## Флаги

`assets/flags/<ISO3>.svg`, 255 штук: все коды ISO 3166-1 плюс непризнанные с нашей карты.
Скачиваются `tools/fetch-flags.mjs`. Берутся все, а не только наши двести: за партию
страны появляются и исчезают, и флаг должен найтись для любой.

## Снимок экрана для проверки

```
godot --path . -- --shot=C:/tmp/ui.png --shot-frame=90 --shot-days=730 --shot-tab=1 --shot-mouse=250,164
```

| Ключ | Что делает |
|---|---|
| `--shot-days=N` | прокручивает партию на N суток разом |
| `--shot-tab=N` | открывает вкладку с номером |
| `--shot-click=x,y` | щёлкает по карте, чтобы снять карточку страны |
| `--shot-mouse=x,y;x,y` | ведёт курсор по точкам, по восемь кадров на каждую |
| `--shot-window` | открывает окно производства |
| `--shot-focus=x,y,zoom` | наводит камеру |

`--shot-days` крутит по двадцать суток за кадр, а не все разом. Сотня тиков в одном кадре
вешает его на секунды, а зависший кадр Windows считает отказом видеодрайвера и сбрасывает
его вместе с игрой — так и вышло дважды. По той же причине кадры ограничены шестьюдесятью
в секунду: раньше инструмент выключал вертикальную синхронизацию ради замера.

Отдельная ловушка того же рода — узлы. Цикл «пока детей больше нужного — QueueFree»
крутится вечно: `QueueFree` удаляет в конце кадра, и счётчик детей внутри цикла не
меняется. Обрезать список узлов надо через `Ui.Trim`, который сперва вынимает ребёнка из
дерева и только потом освобождает.

Порядок жёсткий: прокрутка, вкладка, щелчок, потом курсор. Иначе наводиться не на что —
мышь успевает пройти по точкам до того, как панель открылась. Несколько точек в
`--shot-mouse` нужны, чтобы проверить вложенные подсказки: навести на термин и уйти с него,
оставаясь в первой подсказке.

`--shot-days` нужен почти всегда: сутки идут за секунду, и без прокрутки панель показывает
четвёртый день партии, где половина чисел ещё нули. `--shot-mouse` шлёт событие движения
отдельно — без него подсказки не открыть.
